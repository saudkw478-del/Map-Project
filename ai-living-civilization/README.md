# مدينة الذكاء الاصطناعي الحية — AI Living Civilization

عالم 2D بالبكسل يعيش فيه ناس ذكاء اصطناعي مستقلين. أنت مراقب بس، ما تتحكم فيهم.
المرحلة 1: **خالد ونورة** في بلدة صغيرة (بيتين، سوق، ورشة، ساحة).

> **وين وصلنا:** الخطوة 0 (الهيكل) ✅ — باقي الخطوات 1 إلى 8. هذا الملف يتحدث مع كل خطوة، والشرح الكامل ينكتب في الخطوة 8.

## شنو تحتاج
- **للتشغيل العادي:** Docker بس. (ما تحتاج تثبت Node على جهازك.)
- **للتطوير (اختياري):** Node.js 22 أو أحدث.

## شغّله بـ Docker (الطريقة الأسهل)
```bash
cd ai-living-civilization
cp .env.example .env        # (اختياري) لو تبي تغير شي. بدون .env يشتغل بالموديل الوهمي
docker compose up --build
```
افتح المتصفح على **http://localhost:3000** ولازم تشوف: السيرفر شغال ✅، الاتصال المباشر متصل ✅، الذكاء الاصطناعي: موديل وهمي.

تطفيه: `Ctrl + C`، أو `docker compose down`.

## شغّله للتطوير (بدون Docker)
```bash
npm install
npm run dev          # السيرفر على 3000 والواجهة على http://localhost:5173
npm test             # الاختبارات + فحص أن ما فيه مفاتيح بالكود
```

## ملف `.env` (الأسرار والإعدادات الشخصية)
| المتغير | معناه |
|---|---|
| `LLM_PROVIDER` | `fake` = موديل وهمي بدون مفتاح (الافتراضي). `openai` = API متوافق مع OpenAI |
| `LLM_BASE_URL` | رابط الـ API. الافتراضي رابط Gemini المتوافق مع OpenAI |
| `LLM_API_KEY` | مفتاحك من Google AI Studio. **لا ترفعه على GitHub** (الملف `.env` مستثنى) |
| `LLM_MODEL` | اسم الموديل (الافتراضي `gemini-2.5-flash`). أسماء الموديلات تتغير، تأكد منها في AI Studio |
| `PORT` · `LOG_LEVEL` · `DATA_DIR` | المنفذ ومستوى السجلات ومكان قاعدة البيانات |

لو حطيت `LLM_PROVIDER=openai` وما حطيت مفتاح، السيرفر يوقف ويقول لك بالعربي وش ناقص.

## ملفات الإعدادات (مجلد `config/`)
- `world.json` — سرعة الوقت (إيقاف / عادي / سريع)، وحدود الطلبات بالدقيقة وباليوم.
- `characters.json` — خالد ونورة: طباعهم وأهدافهم ومخاوفهم وأسلوب كلامهم.
- `safety.json` — كلمات ومواضيع يمنعها فلتر السلامة (تتعبى في الخطوة 3).

بعد تعديلها أعد تشغيل السيرفر.

## شلون تتأكد أن الخطوة 0 تمام
1. `npm test` يطلع ✅ لكل الاختبارات وما فيه مفاتيح.
2. `docker compose up --build` ثم افتح http://localhost:3000.
3. جرب تغلط: حط `LLM_PROVIDER=openai` بدون مفتاح، لازم يطلع لك خطأ بالعربي.
