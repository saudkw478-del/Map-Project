## الفكرة
عالم افتراضي 2D (ستايل بكسل مثل مشروع Generative Agents من ستانفورد) يعيش فيه أشخاص ذكاء اصطناعي مستقلين تماماً. أنا مجرد مراقب، ما أتحكم فيهم. العالم يبدأ برجل وامرأة، ومع الوقت يتزوجون وينجبون، والأجيال تكبر لين تصير قرية ثم مدينة ثم حضارة. كل الأحداث تطلع من نفسها (Emergent Behavior)، مو قصة مكتوبة مسبقاً.

## أول شي: شوف وش موجود
قبل أي شي، شوف المجلد الحالي. لو فيه مشروع بدأ (مثل ai-living-civilization/ فيه الخطوة 0 جاهزة) كمّل عليه ولا تعيد البناء من الصفر. وقول لي وش لقيت.

## المطلوب: المرحلة 1 فقط
لا تبني المراحل الجاية، بس صمم الكود بحيث يسهل نضيفها بعدين.
1. خريطة 2D صغيرة: بيتين (من الداخل)، سوق، مكان شغل، ساحة. استخدم Phaser 3 مع tilemap.
2. شخصيتين (رجل وامرأة): خالد ونورة (الأوصاف في config/characters.json). لكل واحد:
   - شخصية مختلفة، أهداف، مخاوف، مهارات، شغل، فلوس، احتياجات (جوع، نوم، طاقة، وحدة)
   - ذاكرة طويلة المدى (memory stream) مع تقييم أهمية + استرجاع حسب الحداثة والأهمية والصلة
   - تخطيط يومي + تأمل (reflection) دوري
   - علاقة بينهم تتطور (غرباء ← معارف ← أصدقاء…)
3. يتكلمون عربي بلهجة خليجية بسيطة، وكل شخصية لها أسلوب كلام مختلف.
4. الوقت مسرّع وقابل للتعديل من ملف إعدادات، وأقدر أغيره من الواجهة (إيقاف / عادي / سريع).
5. العالم يكمل لما أطفي المتصفح، ولو السيرفر طفى يعوّض اللي فات بشكل مختصر لما يرجع.
6. صفحة "ماذا حدث وأنا غائب؟" تعرض أهم الأحداث بالترتيب.
7. أقدر أضغط على أي شخصية وأشوف أفكارها وذكرياتها وحالتها.

## قيود مهمة جداً
- كل شي مجاني. السيرفر Oracle Cloud Always Free (ARM64، 2 معالج، 12 جيجا رام، بدون كرت شاشة).
- الذكاء الاصطناعي عن طريق API متوافق مع OpenAI، والرابط والمفتاح والموديل من ملف .env (Gemini المجاني أول، وراوتر مثل FreeLLMAPI لاحقاً). لا تحط أي مفتاح بالكود أو المستودع.
- يشتغل بالموديل الوهمي (fake) بدون مفتاح عشان أجرب كل شي قبل.
- وفّر الطلبات: الروتين (نوم، أكل، مشي، شغل) بقوانين برمجية بدون ذكاء اصطناعي. الذكاء الاصطناعي بس للسوالف والتخطيط والقرارات المهمة. حد أقصى بالدقيقة وباليوم، ولو وصل الحد العالم يكمل بالقوانين بدون ما يوقف.
- لو الـ API رجع خطأ أو 429، أعد المحاولة بتأخير وما يطيح العالم.
- لا تثبت أي شي على جهازي إلا اللي لازم للتطوير، وكل شي يشتغل بـ Docker. لا تشغل npm install أو أي سكربت من الإنترنت بدون ما تسألني.

قواعد الرسومات (مهمة):

  - مستودع ستانفورد فيه مجلد رسومات اسمه "Cute RPG World 40 usd packet" (حزمة مدفوعة تقريباً 40 دولار). **لا تنسخها ولا تستخدمها.** لو أبيها أنا أشتريها بنفسي.
