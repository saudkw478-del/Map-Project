# الغراب ثلاثي العيون: ذكاء اصطناعي حقيقي (اختياري)

يقرأ الدردشة من سيرفر ماينكرافت، وإذا كتب لاعب رسالة تبدأ بـ `!غراب` أو `!اسأل` أو `!raven` يسأل Claude ويرد على الدردشة بشخصية الغراب.
مثال: `!غراب وين أروح الحين؟` ← يجاوبك حسب حالة الحملة (الشتاء والقلاع الصامدة والساقطة).

## المتطلبات
* **سيرفر مخصص** (مو لعب فردي ولا LAN) مع RCON مفعّل. استخدم `server/docker-compose.yml` (فيه RCON جاهز).
* **مفتاح API** من حسابك في Anthropic (فيه تكلفة استخدام).
* Python 3.9 أو أحدث. لا يحتاج مكتبات إضافية.

## التشغيل
1. شغّل السيرفر بـ`docker compose up -d` (في مجلد `server/`) وضع العالم في `server/mcdata/world`.
2. انسخ `ai/.env.example` باسم `ai/.env` وعبّئه (المفتاح وكلمة RCON نفس اللي في docker-compose).
3. `python3 ai_bridge.py`. إذا ظهر `RCON connected` فهو شغّال، واكتب في اللعبة `!غراب مرحبا`.

## أمان وتكلفة
* لا تشارك ملف `.env`. الحدود الافتراضية: رد كل 12 ثانية لكل لاعب و60 ردًا في الساعة (تغييرها بـ`COOLDOWN_SEC` و`MAX_PER_HOUR`).
* الرد يُرسل بـ`tellraw` مبني بـ JSON آمن، فلا يقدر اللاعب يحقن أوامر.
* الاختبار: `python3 test_bridge.py` (يستخدم سيرفر ونموذج وهميين. ما يحتاج مفتاح).
