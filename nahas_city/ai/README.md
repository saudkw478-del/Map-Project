# الجني الحكيم: جسر الذكاء الاصطناعي

يقرأ سجلّ الخادم ويردّ في اللعبة عبر RCON بشخصية «الجني الحكيم» (عربية مبسّطة، آمنة للأطفال).

## التشغيل
1. في `server.properties`: `enable-rcon=true` و`rcon.port=25575` و`rcon.password=...` ثم أعد تشغيل الخادم.
2. ضع المفتاح في البيئة (لا تكتبه في الكود):
   ```
   export ANTHROPIC_API_KEY=sk-ant-...
   export RCON_PASSWORD=...
   export LOG_PATH=/مسار/الخادم/logs/latest.log
   python3 ai_bridge.py
   ```
   يمكن وضع المتغيرات في ملف `.env` بجانب السكربت.
3. النموذج الافتراضي `claude-haiku-4-5-20251001`، ويُغيَّر بـ `CLAUDE_MODEL`.

## كيف يسأل اللاعب؟
- في الدردشة: `!جني كيف أبدأ؟` (أو `!اسأل` أو `!genie`).
- زر التلميح `/trigger nh_ask`: يضع CORE الوسم `nh_asking` فتحوّله `nahas:npc/ask_request` إلى `nh_askq=1` فيلتقطها الجسر كل ثانية ونصف ويردّ.

## الحدود والأمان
- مهلة 15 ثانية بين أسئلة اللاعب، و20 سؤالًا في الساعة للاعب، و120 للجميع (`COOLDOWN_SEC`, `MAX_PER_HOUR_PLAYER`, `MAX_PER_HOUR_TOTAL`).
- ردّ من جملة إلى ثلاث، بلا أوامر ولا إحداثيات، والأسئلة غير المناسبة أو محاولات تغيير التعليمات تُرفض بلطف.
- الردّ يصل للاعب السائل فقط (`REPLY_ALL=1` ليراه الجميع).

## الاختبار (بدون لعبة ولا مفتاح)
`python3 test_bridge.py` يشغّل خادم RCON وواجهة Claude وهميين.
