# برومبت لـ Claude Code المحلي (ويندوز)

انسخ النص التالي والصقه في Claude Code على جهازك بعد ما تفك الضغط عن الملفات:

```
لا تبني شيئًا ولا تنزّل شيئًا آخر.

مهمتك الوحيدة: نسخ ملفات جاهزة إلى مجلد العالم في ملف CurseForge لدي.

1. مجلد الملفات المفكوكة عندي: <ضع هنا مسار مجلد Nahas_City_World بعد فك الضغط>
   (يحتوي على مجلد NahasCity)
2. ابحث عن Profile واحد فقط باسم "Vanilla 1.21.4" (أو الاسم الذي أعطيتك) داخل:
   %USERPROFILE%\curseforge\minecraft\Instances\
3. انسخ مجلد NahasCity كاملًا إلى: Instances\<اسم الـ Profile>\saves\
   - إن وُجد مجلد بنفس الاسم فلا تكتب فوقه؛ اسأل عن اسم بديل (مثل NahasCity_2).
4. لا تلمس أي Profile آخر ولا أي ملف خارج مجلد saves ذاك.
5. لا تقبل أي EULA ولا توافق على أي شروط نيابة عني، ولا تشغّل ماينكرافت ولا CurseForge.
6. لا تحمّل أي شيء من الإنترنت ولا تثبّت أي برنامج ولا تعدّل الإعدادات.
7. في النهاية اعرض لي المسار الكامل لملف level.dat بعد النسخ وقل لي "تم" فقط.
```
