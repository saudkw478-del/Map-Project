# Shabo War Server (FiveM / QBCore)

سيرفر حرب عالمي، خفيف على اللاعبين، وظايفه عسكرية مع تلفون وقليل من المدنيين.

## الهيكل
- `resources/[shabo]/shabo_war` — سكربت الحرب (ولايات، جيوش، أسلحة، درون، صواريخ، باتريوت)
- `resources/[shabo]/shabo_jobs` — الوظائف العسكرية والعامة والرواتب
- `resources/[shabo]/shabo_borders` — الحدود والمنافذ
- `resources/[shabo]/shabo_ui` — اللوقو وشاشة التحميل والبانرات
- `docs/` — الخطة والملاحظات

انظر `docs/ROADMAP.md` للخطوات.
